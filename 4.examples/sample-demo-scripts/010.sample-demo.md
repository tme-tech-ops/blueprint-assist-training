# Blueprint Assist Demo Script

- Audience: Blueprint authors, team leads, DevOps engineers, quality assurance
- Topics: Customer pattern learning, convention extraction, interactive review, pattern validation, team sharing, CI integration
- Key Skill: Extracting organizational conventions from existing blueprints and enforcing them on new blueprints

## Session Setup

- **Session Type**: Fresh session
- **Bypass Mode**: Enabled

## Prerequisites

- No DAP orchestrator connection is required - pattern learning is entirely local
- Prepare a directory with 3-10 existing blueprints that share naming, network, or structural conventions
- If no blueprints are available, use `4.examples/target-build-folder/` as a starting point
- Prepare one blueprint with intentional convention violations for the validation step

## Quick Start: How to Run It

**Extract patterns:**

```bash
dap-bpa knowledge patterns learn --blueprints-dir ./our-blueprints
```

**Validate a blueprint:**

```bash
dap-bpa knowledge patterns validate ./new-blueprint/blueprint.yaml
```

**Share patterns:**

```bash
dap-bpa knowledge patterns export --output team-patterns.json
dap-bpa knowledge patterns import --input team-patterns.json
```

## Notes

- Customer pattern learning is entirely local - no orchestrator, no LLM, no internet required
- The extraction pipeline is **deterministic** - same blueprints always produce the same candidates
- Confidence scoring uses a sliding-window feedback algorithm (0-100) that adjusts as you accept/reject over time
- Pattern sets are isolated under `~/.blueprint-assist/knowledge/patterns/<set>/` - operations on one set never affect another
- All writes are atomic - a crash during extraction or review never corrupts the store
- Six pattern types: **naming**, **network**, **policy**, **structure**, **variable**, **constraint**
- The `my-dap-patterns` IDE skill routes `ingest`/`validate`/`status` intents to the CLI
- MCP pattern tools (`pattern_learn`, `pattern_review`, `pattern_record_decisions`, `pattern_validate`, `pattern_status`) provide programmatic access
- For the full reference, see [Section 023 - Customer Pattern Learning](../../1.sections/section-023-customer-patterns/content.md)
